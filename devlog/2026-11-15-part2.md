### 4. 開場運鏡（`FlyIntro`）

- 只有 Level 1/2 會播：Level 0 有 `IntroSpot`，不播。
- Level 2 過了 checkpoint 後（`OnStageCleared` / `SkipToStage2`）也會播一次：2-1 起點 → 2-2 終點 → 總覽。

### 5. 受阻時走到最遠的地方（`route_steps.py`）
- 沿著 PathNode 鏈每 175 cm 放一個 TargetPoint `Route_NNN`（`Editor/Route`），tag 是 `RouteStep` 和 `Prog:<目標>:<剩餘 cm>`。剩餘長度用 Dijkstra 在節點圖上計算。Level 2 共 133 點。
- `BP_PathfindingCharacter.StartRun` 走不到終點時，走到「走得到、`Prog` 最小」的點（例如沒轉的橋前面），再報 BLOCKED。
- `rebuild()` 會自動重建這些點。
- **踩坑過程**：
  - 原本用「離終點最近的 PathNode」：角色會走到直線距離最近的 T 字頂端死路。
  - 改成沿路線計算剩餘長度後，角色會停在橋前。

## 遇到的問題

| 問題 | 解法 |
|------|------|
| PIE 執行中 editor world 是 None，BP 存檔失敗 | 請使用者先停掉 PIE |
| DSL `Write` JSON 太長被截斷 | 拆成幾次寫入 |
| `set` 一個不存在的變數 | 先用 Python `add_member_variable` 加變數 |
| 和組員的 `UpdateOcclusion` 在 BP 上衝突（二進位） | 用 `git lfs smudge` 取出對方版本讀 DSL，再加進我們的版本，最後 `--ours` |
| Level 1 沒有遮擋挖空效果 | Editor 用的是舊材質，重新載入 69 個 `/Game/Dev/Materials` 套件；Level 1 外皮牆（`M_TerrainTriplanar`）本來就沒有接挖空 |
| 新版拱門柱子太粗 | 改成只會縮小 |
