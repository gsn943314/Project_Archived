## 遇到的問題

| 問題 | 解法 |
|------|------|
| 改共用藍圖（DSL Write）後，關卡裡的 Point A 不見（發生 4 次：Level 2、Camp、Level 0 兩次） | 每次改完藍圖檢查 Point A，沒有就在 `PathA_00` 重放並指定 `TargetPoint = PointB_Target`；根本原因還沒找到 |
| Level 0 NavMesh 只長在方塊附近 | 走道一格寬，半徑 120 會把走道侵蝕光 → 這關 `RecastNavMesh` 半徑用 35（反正有 `SnapCell` 走中間） |
| 藍圖 `and` 不會短路，滑鼠指到空處時讀 None 的 tag，每幀報 `Accessed None` | hover 判斷改成兩層 `if` |
| 跑步動畫加速 1.8 倍，頭狂晃 | 換 Fast Run、一律 1 倍速播放 |
| 每個轉角停一下、跑步動畫重播 | 連續 `AddMovementInput` ＋ 跑步狀態延遲 0.25 s 才切出 |
| 樓梯上的轉角被對齊到樓梯半途 → 走下樓梯側邊卡住 | `SnapCell` 只在平地全對齊，樓梯只對齊一軸並補上樓梯腳 |
| Storybook 外皮的樓梯和樓梯模型兩層重疊 | 外皮不做樓梯分身 |
| 正交 isometric 鏡頭切換時飛走、看起來怪 | 改回窄視角透視 |
| Camp 鏡頭放 130 m 外整片發白（不是霧也不是大氣散射，推測是 Storybook 後製） | 視角放寬到 60°，鏡頭距離約 56 m |
| 剪貼簿：Python 沒有 `copy_selected_actors_to_clipboard` | `execute_console_command('EDIT COPY' / 'EDIT PASTE')` |
| `save_dirty_packages` 會一起存其他開著的地圖 | 之後只存目前關卡，避免動到 `Content/Dev` |
