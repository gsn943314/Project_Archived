## 完成的功能

### 1. 合併組員分支
- `origin/main`（苔石／小石頭挖空）、`feature/gizmo-icons`、`feature/fox-look`、最後一次 `origin/main`（漫畫 Glitch、`BPC_AssetReload`）。
- 每次只有 `CLAUDE.md` / `AGENTS.md` 衝突：兩邊新增的段落都保留。
- **踩坑過程**：
  - merge 時 Editor 開著。記憶體裡舊版的 `BP_PathfindingPlayerController` 被存回硬碟，蓋掉組員有 Gizmo 的版本，`reload_packages` 也載不回來。
  - 最後在 Editor 裡用 DSL 補回組員那一行（BeginPlay 最後 spawn director）。
  - `BP_PathfindingGameMode` 也一樣是舊版，同樣補回 spawn 那一行。

### 2. Gizmo 提示圖示朝向鏡頭
- `BP_GizmoDirector` 複製到 `Pathfinding/`（`Content/Dev` 原版不動），controller 改成 spawn 這份副本。
- 在 Tick 裡每幀用 `GetPlayerCameraManager.GetCameraRotation` 重算 `FaceDir`：升降、出口這些直立圖示會跟著玩家目前的鏡頭轉。

### 3. 小狐外觀進度（`Pathfinding/BP_FoxLook`，複製自組員的 Dev 版）
- **Level 0**：
  - 開場是彩色。開場動畫結束、進灰盒時（`bWaitIntro`：看到 controller 的 `bInIntro` 從 true 變回 false）變成灰模。
  - 灰模走路時有程序性晃動：`WalkT` 依速度累加，用 sin 做上下彈跳、搖擺和扭轉。
  - 走到塔（`SM_StoneMonument`，yaw 改成 0，正面朝路）前的 `MonumentStand`（tag `LookStand`）時面向塔，播「修復素材」演出，變成白模。
- **Level 1**：開場是白模，走到出口旁石碑（`SM_MossStone2`）旁的 `MonumentStand`（350, 525），變成彩色。
- **Level 2**：開場就是彩色。
- 繞路的修改：
  - 新增 `AddSnapped`，轉角對齊格子中心。
  - 站位點如果本來就在路線上，就不繞路。
  - 只有「這一趟真的會走到出口」時才插入繞路（`RunDestination` 就是出口，而且和出口同高）。

### 4. Level 0 擋路提示
- TargetPoint `CliffStop`（tag `BlockedStop`、`Say:` 三句），位置 (-890, 350)，貼著山。
- `BP_PathfindingCharacter.StartRun`：走不到終點、而且有 `Editable` 方塊在停點 1000 cm 內（方塊沒移走）時，小狐停在這個點。
- Controller：
  - `ShowHint`：轉身面向方塊，記下要說的台詞。
  - BLOCKED 回到起點後，`StartHintDialog` / `UpdateHint` 用 `WBP_Dialogue` 每句顯示 2.8 秒，全部說完收起來。
  - 接著在方塊上畫上下浮動的黃色箭頭和外框，直到方塊被移走、坑被填或按 PLAY。
- 停在山前時（`bHintPending`），`UpdateOcclusion` 不挖空。
- `IntroSpot` 移到 (-1165, -18)，開場時小狐站在佈告欄正前方。
- 修好 Level 0 的 `PointA_PathfindingCharacter` 不見的問題：在原位置重放，目標設 `PointB_Target`。不見的原因查不到。

### 5. Level 1 受阻時停在坑前
- 跑 `route_steps.build()`，建了 73 個 RouteStep，`PointB_Target` 也補上 `Goal:` tag。

### 6. 走格線（`BP_PathfindingCharacter.SquareHops`）
- 兩個路徑點之間如果是斜線、而且在同一高度，就補 L 形轉角：先 X 後 Y，走不通才先 Y，兩段都要 `NavigationRaycast` 沒被擋。
- `StartRun` 和 FoxLook 的繞路都會呼叫它。
- **踩坑過程**：
  - 原本只把「轉角」對齊格子中心。NavMesh 在空曠的地方會給斜線，Level 1 最後一段就是從 (350,525) 斜切到出口 (0,875)，走進台階和拱門旁邊。

### 7. 走進傳送門（`BP_PathfindingPlayerController.EnterPortal`）
- 抵達有下一關或結束動畫的終點時：
  - 小狐沿面向再走 3 公尺（另外用 `PortalHops` 陣列設定 `Hops`）。
  - 在前方播 `NS_PortalMotes`。
  - 0.5 秒後鏡頭 1.2 秒淡出成暖白色（`StartCameraFade`），然後切關或播結束動畫。

## 遇到的問題

| 問題 | 解法 |
|------|------|
| merge 後 Editor 把舊版 controller / GameMode 存回去 | 從 git 還原沒用，因為 Editor 不肯重新載入；直接在 Editor 裡補上組員的改動 |
| `execute_python` 的參數是 `script: {content, language}`，`print` 看不到輸出 | 用 `raise Exception(...)` 把結果帶回來 |
| 撞山的停點不在格子中央，小狐走過頭再回頭，跟拍鏡頭跟著轉 180° | 停點和格子中心放在同一格的靠山側 |
| 提示文字一次全部擠在一起 | 改成用 `Lines` 陣列和計時器，一句一句顯示 |
| Level 1 繞路的站位點不在格子上，小狐斜走 | 放 `LookStand` 在路線的轉角 (350,525)，加上 `SquareHops` |
| Level 1 受阻時被拉去終點 | 上層走道離出口直線只有 3.5 公尺，觸發了 9 公尺的繞路；改成只在走得到出口的那一趟才繞 |
| Mac 不能用 `RecordViewport` 錄影 | 改用 `CaptureGameViewport` 連拍截圖 |
| 改藍圖時 PIE 還開著，`save_asset` 回傳 False | 先停掉 PIE 再存 |
