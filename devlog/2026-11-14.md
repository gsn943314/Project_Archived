### 5. 手動美術保護

- 生成的美術帶 `VisFinal` + `ArtAuto` + `Gen:<transform>`。
- `prepare_art()`：被移動/旋轉/縮放的 → 拿掉 `ArtAuto`（鎖住）；沒動過的 → 刪掉重建；曾生成但現在不見的位置（刪掉/替換）記在 `Art_Registry` 的 `Slot:` tag，不再補。
- `reset_selected_art()`：選取的件恢復自動版本。
- 實測：傳送門上移 100 → Apply Art 後被鎖住；Reset 後回到原位並恢復 `ArtAuto`。

### 6. 編輯模式操作

- 左鍵在空白處拖曳＝平移（`StartLeftPan`）；滾輪縮放；右鍵左右拖＝繞畫面中心旋轉 yaw（俯角固定）。
- PLAY 中的視角旋轉移除。
- 主選單「快捷鍵」三語文字同步更新。

**踩坑過程**：

- 右鍵旋轉一開始用 `GetMousePosition`，右鍵按住時游標被 capture 不會變 → 旋轉量為 0；改用 `GetInputMouseDelta`。

## 遇到的問題

| 問題 | 解法 |
|------|------|
| Renumber 只選 2 點時把其他點都設為 Unused，第一次的順序無法還原（undo 歷史與自動存檔都沒有） | 把 Unused 點全部改回路徑點讓使用者重排；加上執行前確認 |
| 誤存了組員的 `Content/Dev/Lvl_Camp_Whitebox.umap` / `L_Assets.umap` | 先切到別張地圖，再 `git checkout origin/main -- <檔案>` |
| 在 V5_Art 誤按 Apply Art 並存檔 | 切到別張地圖 → `git checkout HEAD -- Lvl_BlockTutorial_V5_Art.umap` → 重新開啟 |
| 美術調整後 PIE 測試太頻繁、太慢 | 規則：路徑測試只在使用者要求時跑；測試時 `set_global_time_dilation(3)` |
| 每次都 push 到 main | 規則：只 commit 在本機，使用者說要 push 才 push |
