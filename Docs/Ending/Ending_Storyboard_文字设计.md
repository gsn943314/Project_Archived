# 结尾过场 · 冒险者公会

结尾接在 Level 2 后。小狐走出山洞，抵达原 Demo 的公会。柜员把它当成回来接活的冒险者。名册上的画像和短暂恢复的旧开场，让小狐认出自己曾是主角。

工作室里仍在运行玩家刚走过的测试。开发者路过显示器，看到测试恢复了旧 Demo 的画面。两人想起当年光顾着探索的乐趣，于是决定把当初搁下的路做下去。最后回到小狐，给它踏出公会门槛的一刻留白。Level 0 和公会相隔很远，通过递接委托的动作呼应，两处各有自己的委托。

## UE 实现与预览

- `/Game/Dev/Cinematics/Ending/WBP_Ending_Cutscene` 管理换图、英文字幕、音轨和淡出。正式流程调用 `PlayCutscene`，通过 `OnEndingFinished` 接回游戏。
- 八张主画面都是 1920 × 1080（16:9）。水粉延展层与主画面同步切换，只填充视口超出主画幅的部分。
- 当前音轨是环境、动作和旋律的试播混音，人物对白用字幕呈现。
- 在 `Lvl_Level0_Storybook` 中按 **O** 预览。正式 Level 2 主流程的触发由关卡接入。
