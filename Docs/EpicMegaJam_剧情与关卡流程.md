# Epic MegaJam · 剧情与关卡流程

**游玩顺序：Level 0 → Level 1 → Level 2 → 结尾。** Level 2 是最后一个解谜关卡。

小狐原本是制作团队一款休闲冒险 Demo 的主角。开发过程中，团队受到压力，放下了原本想做的游戏，转而开发另一个版本。小狐被留在新游戏的开场过场里，成了一个只负责张贴冒险任务的 NPC。压力来自发行商、团队内部，还是两者都有，暂未确定。

玩家一开始以为自己在测试新游戏。随着被删掉的场景和记录重新出现，玩家沿原冒险的时间线往回走：**从原故事的结尾出发，经远征庆祝营地和探险途中，回到冒险最初开始的公会。** 小狐逐渐恢复外形和记忆，世界则逐渐露出缺失资产、调试几何和新旧版本交错的痕迹。

玩家在编辑模式调整物件和机关，点 Play 后由小狐自动寻路。这个规则贯穿全程。正式 Play 画面隐藏导航调试线。

## Level 0 · 开场测试与假结局

**在原故事中的位置：结尾。** 制作团队沿用原故事结尾处的场景，把它改成新游戏的开场过场。

1. **0-1 · 公告牌。** 玩家一开始只能点 Play。小狐以简单的白色白盒形象出现，自动走到公告牌前张贴冒险委托。周围环境已经有完整美术，小狐却只剩一个固定动作。演出途中出现画面异常和缺失资产，测试被打断，玩家被退回编辑模式，开始看见操控手柄和部分碰撞信息。
2. **0-2 · 第一次编辑。** 更大的场景向玩家开放。公告牌所在的起点浮岛与第二片区域之间是虚空。玩家解锁 Move，用两根装饰石柱搭出通路，再按 Play，让小狐自动跨过去。
3. **假结局。** 第二片区域尽头的传送门看起来像一个任务完成或结局出口，实际把小狐带到 Level 1，进入原故事更早的一段。

当前关卡已搭出起点浮岛、虚空、第二片区域和出口布局。公告牌演出、异常触发、编辑权限解锁和两根石柱的具体落点，还需要串成可玩的完整流程。

## Level 1 · 最后的远征营地

**在原故事中的位置：接近结束。** 远征已经成功，营地在庆祝。帐篷、篝火、旗帜、补给箱和中央纪念庭院承载这种气氛。

1. **进营地。** 小狐从下层传送门 A 抵达，沿前廊走向左侧营地，经楼梯上到高架石廊，最后前往中央纪念庭院与 B 点。可编辑物围绕路线布置，交接设定包括补给箱、可旋转护栏和石柱。
2. **遇见旧同伴。** 一名旧版冒险同伴会自动寻路靠近小狐。编辑模式里，同伴看起来像敌人。被挡住时，同伴仍会在远处祝贺小狐。成功接触时，会触发更完整的重逢对话，同时打断这次自动寻路，需要重新测试。两种结果都让玩家知道对方认得小狐。
3. **庆祝过场。** 中央庭院触发一段受损的旧版庆祝演出，暗示这里曾是小狐那趟远征的尾声。随后开放通往 Level 2 的出口。

## Level 2 · 遗忘荒野／空洞神殿

**在原故事中的位置：更早的探险途中。** 这是最后一个解谜关卡。2-1 与 2-2 位于同一张连续地图，中间共用一个 Checkpoint。当前玩法以 `Lvl_Level2.umap`、`CLAUDE.md` 和与关卡对应的 `level2_build.py` 为依据。

### 2-1 · 遗忘荒野

从 A 点前进后遇到岔路，两条路线汇合于第三层的 Checkpoint。

- **右路**：移动路上的箱子并填洞，旋转木桥跨过两格宽的河道，再走楼梯上升三层。
- **左路**：先填洞，可用箱子堵住野兽所在侧室的出口，再搭水车升降梯上升三层。升降梯开场停在上端，编辑时可先把它点到下端接人。

### Checkpoint · 旧版存档

到达第一段终点后，游戏保存新的重试起点，切回编辑模式，镜头移向 2-2，寻路目标改为最终 B 点。

剧情上，这里是原版冒险者的旧存档。系统发现当前公告牌 NPC 与旧版主角的身份引用不一致，尝试恢复旧数据。小狐恢复成更完整的白色骨骼网格，材质和声音仍未恢复。这段角色恢复是叙事设计，演出接入情况待确认。

### 2-2 · 空洞神殿

1. 填洞，走楼梯到第五层，旋转环桥跨过第二条两格宽的河道。
2. 经过高台守卫。守卫的升降梯开场停在上端，留在那里时守卫能搭下来追击。编辑时把梯台点到下端，可以把守卫留在高台。
3. 再填一处缺口，把神殿升降梯叫到下端，搭它上升三层，到第八层的 B 点。通关后进入结尾。

旋转桥每点一次转 90°。升降梯在编辑模式下点击切换停靠端，Play 时小狐或敌人停到梯台上，都可能被送到另一端。

## 结尾 · 冒险者公会

**在原故事中的位置：起点。** 小狐走出山洞，自动走进冒险者公会。公会是原 Demo 开始冒险的地方，这一段以剧情演出收束。

1. **小狐找回身份。** 可以用同一份委托呼应 Level 0：新游戏里的小狐负责把它贴出去，原 Demo 里的小狐曾在公会接下它。公会触发一小段旧版开场或记忆，让小狐认出当初接下委托的人就是自己，理解自己曾经是这场冒险的主角。具体触发物和镜头可以在制作时调整。
2. **团队重拾创作热情。** 视角从屏幕内转到制作团队。他们意外看见原 Demo 的公会重新出现在电脑上，想起当初一起做这个小冒险的乐趣，也想起有哪些东西在改版时被放下了。最后用一个开始做事的动作落地，例如重新打开旧工程，接着做小狐走出公会后的那一幕。
3. **前段埋线。** 可以在 Level 0 的过场备注里留下小狐被改成张贴任务 NPC 的痕迹，在 Level 1 的演出断点提示庆祝场景被移除，在 Level 2 的旧存档附近留下团队对开发方向的分歧。透露到什么程度、压力来自哪里、团队最后怎么说，都留到写演出时再定。

结尾的情绪落点是小狐重新认出自己，团队也重新愿意花时间做自己喜欢的游戏。具体台词保持开放。
