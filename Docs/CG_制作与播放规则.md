# Epic MegaJam · CG 制作与播放规则

以已接入 UE 的 Scene 0 开场为基准。

## 画面与边缘

- 每个正式镜头单独交付 **1920 × 1080（16:9）PNG**，按播放顺序编号。合图用于评审。正式插画必须按 16:9 完整构图并画满画布。较窄的分镜草稿需要扩展真实场景后再输出。水粉补色只用于播放器在 16:9 画幅之外露出的区域。
- 沿用平面的手绘水粉风格，用大色块和少量阴影表现形体。人物配色与五官以角色设定为准，场景结构以关卡资产和确认的分镜为准。
- UE 中把主画面和字幕放在同一个 1920 × 1080 版面内，通过居中的 Scale Box 等比缩放。每镜配一张延展色块贴图铺满视口，跟主画面同步换图，宽屏超出的区域也沿用该镜配色。
- 分镜默认硬切。需要淡出时，主画面、字幕和边缘一起淡到黑。正式接入由关卡流程管理 HUD、导航调试标记和结束回调。

## 语言与字幕

- 比赛面向美国观众，**游戏内的台词、字幕、报错文字和关键提示统一用英文**。团队沟通、分镜记录和交接文档可继续用中文。
- 英文台词用 UMG 文本控件叠在主画面的安全区内，方便独立修改。每格标记字幕和播放时长，试播时检查阅读速度和画面重点。重导尺寸变化的贴图后，把 UMG 图片 Brush 的 Image Size 同步为 1920 × 1080，并在 PIE 检查实际画幅和宽屏延展。
